📖 用語ミニ解説
脆弱性（ぜいじゃくせい）
ソフトや機器の「欠陥・弱点」。攻撃者に悪用されると乗っ取りや情報流出につながる。アップデートで直ることが多い。
CVE
脆弱性ごとに付く世界共通の番号（例: CVE-2026-12345）。同じ問題かどうかを見分けるのに使う。
ゼロデイ
修正プログラムが出る前に悪用が始まっている脆弱性。特に危険度が高い。
悪用確認（KEV）
米国CISAが「実際の攻撃で使われている」と確認した脆弱性の一覧。該当製品を使っていれば最優先で更新を。
ランサムウェア
データを暗号化して使えなくし、元に戻す代わりに身代金を要求するマルウェア。最近はデータを盗んで「公開する」と脅す二重恐喝が主流。
フィッシング
本物そっくりの偽メール・偽サイトでIDやパスワード、カード情報を盗む手口。SMSを使うものはスミッシング。
不正アクセス
権限のない人がシステムに侵入すること。盗まれたパスワードの使い回しが原因になりやすい。
サプライチェーン攻撃
本命の組織ではなく、取引先・委託先・使っているソフトなど「つながり」の弱い所から侵入する攻撃。
DDoS攻撃
大量の通信を送りつけてサービスを止める攻撃。
テイクダウン
警察や企業が協力して、攻撃に使われるサーバーや犯罪サイトを停止・押収すること。「良いニュース」側の出来事。
